# Python Mini Systems

A mini CLI-based Python systems project built while learning backend/runtime fundamentals.

## Features

* User register/login
* Product management
* Search products
* Cart system
* Change cart quantity
* Checkout flow
* Stock validation and mutation

## Concepts Practiced

* Functions
* Loops
* Dictionaries & lists
* Runtime state mutation
* Transactional flow
* Traversal and validation
* Shared state coordination

## Current Status

Work in progress — focused on learning systems thinking and runtime behavior through building.
